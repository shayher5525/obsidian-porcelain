# Porcelain

![Porcelain](screenshot.png)

[English](README.md) · [中文](README_zh.md) · **日本語** · [한국어](README_ko.md) · [Français](README_fr.md) · [Español](README_es.md) · [Italiano](README_it.md)

白磁の質感を持つ Obsidian テーマ —— 半透明の表面、ブルーのアクセント、フラットなコントロール、両端がフェードアウトするセパレーター。

Obsidian 自身の CSS 変数をベースにゼロから書かれています。フォークではなく、サードパーティ製のテーマコードは一切含まれません。

## デザインの原則

このテーマは 5 つのルールに従っており、`theme.css` のすべての宣言はそのいずれかに由来します。

1. **表面は半透明で、同じ色調を共有する。** ペインは不透明なカードではありません。ガラスは単一の固定・空のレイヤーです —— インターフェースを保持するコンテナに `backdrop-filter` を設定すると、子要素が再描画されるたびにフィルター済みレイヤー全体が無効化されるため、ファイルリストへのホバーだけで全ウィンドウのぼかし再計算が発生します。
2. **エンボス加工は一切しない。** 奥行きは 1px のアウトライン 1 本だけで作ります。積み重ねたインセットハイライト、暗い内側エッジ、ドロップシャドウは使いません。
3. **セパレーターは両端でフェードアウトする。** ボーダーは要素にちょうど広がるため、パディングの異なる隣接コンテナは開始・終了位置がずれた線を生成します。両端が透明なグラデーションには、ずれる端点が存在しません。
4. **色付きブロックには軸から外れたグローを載せる。** 焦点・サイズ・減衰が異なる 3 つの放射グラデーション —— どの線形方向も読み取れません。
5. **状態変化は色だけを変える。** パディング、ボーダー幅、位置は決して変更しないため、カーソルの下で何も動きません。

## インストール

1. `manifest.json` と `theme.css` をダウンロードします。
2. 両方を `<vault>/.obsidian/themes/Porcelain/` に配置します。
3. *設定 → 外観 → テーマ* → **Porcelain** を選択します。

### 推奨設定

- *外観 → 透明なウィンドウ*: **オン**。表面は設計上半透明です。オフにするとフラットな色でレンダリングされます。

## カスタマイズ

トークンは `theme.css` 先頭の `.theme-light` / `.theme-dark` と `body` で宣言されています。知っておくと便利なもの:

| 変数 | 制御するもの |
| --- | --- |
| `--pc-tint` / `--pc-veil` | 基本の表面色（RGB タプル）とカバー率 |
| `--pc-sidebar-tint` / `--pc-sidebar-veil` | サイドバーがコンテンツ平面から離れる度合い |
| `--pc-line` | セパレーターとアウトラインの色 |
| `--pc-blue` / `--pc-orange` | 選択・ホバーの塗りつぶし |
| `--pc-bloom-light` / `--pc-bloom-dark` | 色付きブロックのグローグラデーション強度 |
| `--pc-fade-in` / `--pc-fade-out` | セパレーターがフェードし始める・終わる位置 |
| `--pc-popup-bg` / `--pc-popup-blur` | メニュー・モーダル・設定のガラス効果 |

`theme.css` を直接編集するのではなく、CSS スニペットで上書きすることをおすすめします。そうすれば更新で変更が上書きされません。

## プラグインサポート

- **Notebook Navigator** —— 選択・ホバー状態、クイックアクションボタン、ヘッダーレイアウトがテーマに合わせられています。
